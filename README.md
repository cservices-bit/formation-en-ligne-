# C Service Formation

> Plateforme de formation en ligne proposant des cursus web, marketing et design.

[![Jekyll](https://img.shields.io/badge/jekyll-4.3.3-red.svg)](https://jekyllrb.com/)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Made with](https://img.shields.io/badge/Made%20with-HTML%2FCSS%2FJS-green)]()

Plateforme de formation en ligne proposant des cursus web, marketing et design. Accès à vie, certificats officiels, support 7j/7. Catalogue avec prix promo, témoignages, newsletter, formulaire contact et WhatsApp. Design responsive moderne pour convertir les visiteurs en apprenants.

## 🚀 Technologies utilisées

- HTML5
- CSS3 (Flexbox, Grid, variables CSS)
- JavaScript (ES6)
- **Jekyll** (thème GitHub Pages)
- Design responsive
